CentOS Squid Proxy Server Setup

📌 Project Overview
A fully functional Squid proxy server configured on CentOS 7 using VMware Workstation. This project demonstrates the complete setup, configuration, and testing of a proxy server for HTTP/HTTPS traffic.

🛠️ Technologies Used
- *OS:* CentOS 7
- *Proxy Software:* Squid
- *Virtualization:* VMware Workstation
- *Tools:* vi, systemctl, firewall-cmd, curl

⚙️ Features
- HTTP/HTTPS proxy on port 3128
- Client authentication (optional)
- Access control using ACLs
- Firewall and SELinux configuration
- Real-time log monitoring
